SOFTWARE LOAD, SD CARD ROUTE
2.1.1
Introduction.
InkOS loads onto the X4 with an iPhone only: the cloud builds the image, the phone carries it to the microSD card, and the bootloader is reported to write it. The file must be named update.bin, in the card root (figure 2.1-1).
2.1.2
Functional Description.
A passing build posts update.bin to the release LATEST. Prove the route first with the CrossPoint release file, then load InkOS the same way; any failure goes to page 2.1-2. On first boot, SETTINGS › DIAGNOSTICS shows each raw reading (figure 2.1-2).
2.1.2.1
Button Decode Bands.
Six buttons share two resistor ladders on GPIO 1 and 2. A reading outside its band is fixed in BOARD.H, not in hardware.
