SOFTWARE LOAD, MALFUNCTION AND ROLLBACK
2.1.4
Prerequisites.
A microSD card formatted FAT32, a USB-C card reader for the iPhone, a USB charger and the X4 charged. No full-flash backup can be made from an iPhone; the stock file in 2.1.6 is the only restore point, so keep a copy in Files before the first load.
2.1.5
Load Decision Sequence.
The proof load separates the route from the code: if the CrossPoint release file will not load, InkOS will not either, and the fault is the unit or the route (figure 2.1-3).
2.1.5.1
Unverified Elements.
The SD loader, the load keys and the SSD1677 controller come from community reports, not from this unit. Treat the first load as a test, not a routine.
